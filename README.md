# status-panel

Claude Code 세션 옆에 상태 패널을 띄우는 모드입니다. 상태 줄에 나오는 정보(위치 · 모델 · 컨텍스트 · 사용량 한도)를 패널 하나에서 보여 주고, 탭을 바꿔 가며 Git 상태, 달력, 하네스(`~/.claude` 와 프로젝트의 설정), 프로젝트 파일을 확인할 수 있습니다.

## 설치

터미널에서 연 Claude Code 세션의 프롬프트에 입력합니다.

```
/plugin install status-panel --marketplace LizeLing/status-panel
```

마켓플레이스를 추가할지 물으면 `y` 를 누르고, 설치 범위(user 를 권장합니다)를 고르면 됩니다. 이어서 나오는 설정 화면에서 `[열기]` 버튼이 파일을 열 앱을 정할 수 있고, 비워 두면 macOS 기본 앱으로 엽니다.

셸에서 설치하려면 다음 명령을 실행합니다.

```
claude plugin install status-panel --marketplace LizeLing/status-panel
```

데스크톱 앱에서는 프롬프트 입력창 옆의 + → Plugins → Add marketplace 에 `LizeLing/status-panel` 을 입력한 뒤 Add plugin 으로 설치합니다.

## 탭

| 탭 | 내용 |
| --- | --- |
| 상태 | 로그인 계정, 위치와 브랜치, 모델 · effort · 버전, 세션 시간 · 프롬프트 수 · 비용, 사용량 한도, 컨텍스트 구성, 시계 |
| Git | 스테이징 · 수정 · 새 파일 수, 추가 · 삭제 줄 수, 브랜치, 최근 커밋, 변경된 파일 |
| 달력 | 이번 달 달력과 주간 한도가 초기화되는 날 |
| 하네스 | 글로벌 · 로컬의 CLAUDE.md · 서브에이전트 · 스킬 · MCP · 훅 목록과 세부 내용, 이 세션에서 사용한 항목, 도구 호출 · 에이전트 활동 |
| 파일 | 프로젝트 파일 트리와, 에이전트가 각 파일을 만들고(C) · 읽고(R) · 고치고(U) · 지운(D) 기록 |

패널을 닫았다면 `/status-panel` 명령으로 다시 엽니다.

## 참고

- 화면의 문구는 한국어입니다.
- `[열기]` 버튼은 macOS 의 `open` 명령을 사용하므로 다른 OS 에서는 동작하지 않습니다.
- 패널이 보이는 동안 `~/.claude/status-panel/<세션 id>` 에 마지막으로 확인한 시각을 기록합니다. 상태 줄 스크립트가 이 값을 읽어, 패널이 보일 때 같은 정보를 두 번 표시하지 않도록 할 수 있습니다.
- MCP 서버 목록에는 서버의 실행 명령과 URL(쿼리 문자열 제외)만 표시하고, 환경 변수와 헤더는 이름만 표시합니다.
